# Field Learning — Actuator belt replacement (Denver DC Rack 12)

Visit findings from field technicians:

Replaced actuator belt and recalibrated torque sensors. Error code A-17 cleared after belt tension set to 45 N and encoder zeroed. Rack had dust buildup on the pulley that accelerated belt wear — recommend inspecting pulley groove during any A-17 callout.
